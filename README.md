# 🗑️ BasuraCero Cuba

> Plataforma web y PWA para la gestión inteligente de la recogida de basura en Cuba mediante Inteligencia Artificial y micro-logística comunitaria.

## 🎯 Descripción del Proyecto

Proyecto universitario desarrollado en la **Universidad de Oriente** como parte de la carrera de **Ingeniería Informática** (Curso 2026-2027). La plataforma resuelve la problemática social de la acumulación de residuos sólidos en las calles cubanas mediante:

- 🔔 Alertas en tiempo real sobre horarios de recogida
- 📸 Reportes ciudadanos con geolocalización y visión artificial
- 🤖 Predicción con IA basada en patrones históricos
- ♻️ Conexión con micro-recolectores independientes
- 🏛️ Dashboard institucional para Servicios Comunales

## 🚀 Instalación

### Requisitos previos
- Python 3.10+
- PostgreSQL 14+

### Backend

```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python manage.py runserver
```
