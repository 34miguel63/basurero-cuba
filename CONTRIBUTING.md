# 🤝 Guía para Contribuir

## Flujo de trabajo

1. Crea una rama para tu tarea: `git checkout -b feature/nueva-funcionalidad`
2. Haz commits pequeños y claros: `git commit -m "feat: añade reporte por voz"`
3. Sube la rama: `git push origin feature/nueva-funcionalidad`
4. Abre un Pull Request hacia `main`.

## Convenciones de commits

- `feat:` Nueva funcionalidad
- `fix:` Corrección de bug
- `docs:` Cambios en documentación
- `style:` Formato, sin cambios de código
- `refactor:` Reestructuración de código
- `test:` Añadir o modificar tests
- `chore:` Tareas de mantenimiento

## Estructura de ramas

- `main` → versión estable
- `feature/*` → nuevas funcionalidades
- `fix/*` → correcciones
- `docs/*` → documentación
